四、发布步骤（10 分钟上线）

  1. GitHub 新建空的公开仓库（不要勾选初始化 README）
  2. 双击 publish.bat 你的用户名 仓库名（首次会弹 GitHub 登录授权）
  3. 仓库 Settings → Pages → Source 选 main / (root) → Save
  4. 等 1~2 分钟，访问 https://用户名.github.io/仓库名/，发到微信/QQ 手机点开即玩
💡 出问题回滚：git checkout v1.0 -- . && git commit -m "rollback" && git push，Pages 自动重新部署、链接不变。
